# O-RAN-CL

A continual-learning benchmark for O-RAN RIC control, built on public O-RAN KPI traces.

Quick start: see the repository root README. Full specification: `docs/BENCHMARK.md`.

Contents of this directory at release:
- `splits/` - frozen environment splits (JSON), so results are comparable across papers
- `REFERENCE.md` - reference results for the 10 methods in the paper
- `SCHEMA.md` - the canonical KPI schema every submission must consume
